Kenapa NxDOM?

⬢

Semua runtime, satu CLI

Backend, Desktop, Mobile, Web Express, dan Web statik — dikelola dari satu tempat dengan pola kerja yang sama.

▣

Modul siap pakai

Tombol, form, navigasi, chart, ikon, dan banyak lagi. Modul wajib tiap runtime dicek dan dipasang otomatis.

✦

Agent AI bawaan

Chat streaming, 22+ provider cloud & lokal. Asisten bisa mengeksekusi install, migrate, hingga update framework — selalu dengan konfirmasi.

↹

Tanpa konfigurasi rumit

Menu interaktif dengan tombol panah. Tidak perlu hafal perintah — tapi tetap ada shell ❯ bagi yang suka ketik cepat.

⊞

EXE portabel

Satu file nxdom.exe untuk Windows — tanpa installer, tanpa Node.js. Salin ke folder mana pun, langsung jalan.

⟳

Server lokal + live reload

Server statis dan PHP bawaan dengan live reload. Ubah file, browser ikut segarkan — tanpa ekstensi tambahan.

Tampilan

Cara mulai

  1. Pasang

    npm install --global nxdom-cli

    atau tanpa instalasi: npx nxdom-cli, atau unduh EXE portabel.

  2. Buka di proyekmu

    cd D:\path\ke\proyek
nxdom

    Menu Runtime langsung tampil.

  3. Pilih runtime → Install → Start

    Module → Install → Config → Start → Log → Stop

    Mobile langsung tampil QR code — scan dari HP, aplikasi berjalan.

npm

Windows, macOS, Linux. Butuh Node.js ≥ 20.17 dan npm.

npm install --global nxdom-cli

Update: npm update --global nxdom-cli

EXE portabel

Windows x64 — satu file, tanpa installer, tanpa Node.js.

File baru diunduh dapat memicu peringatan SmartScreen (belum ditandatangani digital). Verifikasi integritas dengan SHA256 yang disertakan.

Aksi tertentu tetap butuh tool eksternal: npm/npx (Desktop, Mobile, Web), PHP/Composer (Backend), internet (GitHub & provider AI).

FAQ

Apakah NxDOM gratis?

Ya, lisensi MIT.

Apakah butuh Node.js?

Versi npm butuh Node.js ≥ 20.17. Versi EXE portabel tidak butuh Node sama sekali.

Port sudah dipakai (mis. 9002)?

Menu runtime → Stop → Start. Nxdom otomatis mencoba menghentikan proses lama.

Browser tidak terbuka saat menekan w?

Pastikan status berjalan (titik hijau di menu Log), lalu tekan ↻ Refresh.

Rate limit GitHub habis?

Isi GITHUB_TOKEN di konfigurasi atau tunggu reset limit. Cek sumber aktif dengan nxdom info.
